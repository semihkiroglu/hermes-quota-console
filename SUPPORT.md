# Support

This repository is an independent dashboard plugin for
[Hermes Agent](https://github.com/NousResearch/hermes-agent). It is
maintained on a best-effort basis; there is no commercial support and no SLA.

## Ask here

For problems with this plugin and its dashboard:

- Quota/balance cards showing wrong, missing, or stale data.
- Alert thresholds, status banners, or reset behavior problems.
- Settings dialog or card customization issues.
- Installation / update problems with the plugin checkout.

Open an issue using the
[issue templates](https://github.com/semihkiroglu/hermes-quota-console/issues/new/choose).
For security-related reports, follow [SECURITY.md](SECURITY.md).

## Ask upstream

For problems with Hermes Agent itself — dashboard shell, plugin loading
contract, profile/credential management — open an issue at
[https://github.com/NousResearch/hermes-agent/issues](https://github.com/NousResearch/hermes-agent/issues).
